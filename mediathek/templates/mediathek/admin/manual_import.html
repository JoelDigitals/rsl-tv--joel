📝 Manueller Video-Import

Wenn der automatische Import nicht funktioniert, kannst du Videos auch manuell hinzufügen. Füge einfach die YouTube-URLs ein (eine pro Zeile).

{% csrf_token %}
💡 Tipp: Öffne deine Playlist in YouTube, kopiere die URLs der Videos hier rein
💡 So funktioniert's

Schritt-für-Schritt:

  1. Öffne deine YouTube Playlist im Browser
    z.B. https://www.youtube.com/playlist?list=VLPL...
  2. Öffne das erste Video
    Klicke auf das erste Video in der Liste
  3. Kopiere die URL
    Aus der Adresszeile: https://www.youtube.com/watch?v=xxxxx
  4. Klicke auf "Nächstes Video"
    Nutze die Autoplay-Funktion oder klicke auf das nächste Video rechts
  5. Wiederhole für alle Videos
    Kopiere jede URL und füge sie oben ein
  6. Importiere!
    Klicke auf "Videos importieren" - fertig! ✅
⚡ Schneller Trick

Nutze die Browser-Konsole um alle Video-URLs automatisch zu kopieren:

JavaScript-Code (in YouTube-Playlist-Seite): 
// F12 drücken → Konsole öffnen → Diesen Code einfügen:
let urls = [];
document.querySelectorAll('a#video-title').forEach(a => {
  if(a.href) urls.push(a.href.split('&')[0]);
});
console.log(urls.join('\n'));
copy(urls.join('\n'));  // Kopiert automatisch in Zwischenablage!
alert('URLs kopiert! Jetzt hier einfügen.');
✅ Kopiert alle Video-URLs automatisch → Einfach hier einfügen!
